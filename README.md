# Colour Me Curious! 🌈 — 7-minute version

A simple, no-login B1 English speaking warm-up for pairs.

## How to play
1. Pair students up and start the 7-minute timer.
2. Spend about 2 minutes on each of the three rounds: Colours & Feelings, Your Style, and Me & You.
3. Students take turns choosing answers, explaining why, and asking the follow-up question.
4. Encourage them to use at least one **preposition + verb-ing** phrase, such as *interested in trying*, *excited about learning*, *tired of wearing*, or *keen on experimenting*.
5. Finish by sharing one similarity and one difference.

## Run locally
Open `index.html` in any modern browser. No build tools, accounts, or external libraries are required.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. After deployment, open the URL shown in the Pages section.

## Privacy
The game runs entirely in the browser. It does not transmit or remotely store student answers.
